## Проект по курсу Efficient NN

Тема: реализация Triton-кернелей для квантизации весов в LLM и инференса квантизованной модели

## Авторы проекта

Бриленков Евгений, Головкин Иван, Чуфистов Георгий

## INT4-слой

`QuantizedLinear` квантует вес `nn.Linear` вдоль входа, группа 128, коды `[-8, 7]`. Два соседних кода лежат в одном `int8`. `backend="triton"` вызывает кернели, `backend="reference"` считает то же на PyTorch и восстанавливает знак ниббла (`n >= 8` → `n - 16`).

Замер Llama-3.2-1B на WikiText-2: `notebooks/llama_int4_eval.ipynb`, Colab с GPU.

## Установка и запуск тестов

Требуется Python 3.11 или новее. Установите проект вместе с dev-зависимостями:

```bash
python -m pip install -e ".[dev]"
```

Запустите все unit-тесты из корня репозитория:

```bash
python -m pytest
```
